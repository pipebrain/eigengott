# v1.0.0 checkpoint

This is a title-screen prototype checkpoint. The engine, gameplay, enemies, and multiplayer remain future work.

## Default profile

The exact browser-saved **dos-maze** profile is bundled and opens by default; its settings use a 1 px wall, 16 px path gap, and grid snapping off. Earlier defaults remain in the H menu. The separate **dos** and **dos-2x** exports are also preserved. Default startup begins a fresh animation cycle rather than restoring the captured export time.

## Run

From the repository root:

```sh
python3 vector-labyrinth/tools/serve.py --port 8080
```

Open http://127.0.0.1:8080/vector-labyrinth/ in a browser with WebGPU and hardware acceleration. Press **H** for controls. Compiled WebAssembly is included.

See [vector study documentation](../vector-labyrinth/README.md) for build instructions and controls, and [original 3D study documentation](SLICE_STUDY.md) for the earlier app at `/`.

## Known issue reported at checkpoint

The user reports some lines and the “Maze clearance around glyphs” setting do not follow the drawing grid. This issue is intentionally uninvestigated and unfixed in v1.0.0, at the user's request to checkpoint the current work first. Earlier grid-test evidence does not establish correctness around glyph clearance.

The supplied reproducer is preserved as `vector-labyrinth/presets/reported-grid-clearance.json`. Historical verification reports describe their original tested configurations, not acceptance of this reported issue.
