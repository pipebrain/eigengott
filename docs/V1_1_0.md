# v1.1.0 · specialized DOS-maze runtime

The full vector editor initializes and updates machinery for many experiments that the accepted DOS-maze profile does not use. This version adds a standalone `/dos-maze/` runtime containing its guided maze, drifting reference letters, priority changes, and hard flicker/redraw. The full editor, its browser saves, the original 3D app, and the `v1.0.0` checkpoint are preserved.

The hidden H menu contains only playback, quality, fullscreen, and diagnostics. The visual profile is fixed. No grid behavior or glyph-clearance redesign is included; this preserves the accepted free-gap appearance.

## Changes and local evidence

| Measurement | Full lab | DOS-maze |
|---|---:|---:|
| Fixed WASM memory | 64 MiB | 8 MiB |
| WASM binary | about 38 KB | about 7.8 KB |
| Render passes | 4 | 3 |
| Render pipelines | 14 | 6 |
| GPU vector/control buffers | about 10.5 MB | about 1.31 MB |
| 1376×768 uncapped throughput sample | 2215 fps | 2346 fps |
| 3840×2160 uncapped throughput sample | 298 fps | 381 fps |
| 3840×2160 main-thread work per submitted frame | 2.38 ms | 0.18 ms |

These are local Chrome/Metal samples at identical default quality, with frame-rate limits disabled and GPU work drained at measurement boundaries. They measure throughput, not a monitor's physical refresh rate or a guarantee for other hardware. The generator/overlap-cleanup samples improve by approximately 4× at 1376×768 and 11× at 4K.

The compressed binary mask/guide asset is 3595 bytes. WASM rebuilds the exact 4,718,592-byte reference distance-field atlas in reused startup memory. No font rasterizer, editable font library, or external reference image is loaded at runtime.

## Verification

- 376 generator comparisons, including randomized seeds, fractional viewports, corruption levels, and times: byte-for-byte output parity with the accepted profile.
- Exact reference atlas parity and 7200 animation-state comparisons over 120 simulated seconds, including flicker, redraw seeds, and letter hierarchy.
- Six desktop/portrait/high-DPI screenshot comparisons. Maximum mean absolute difference is below 0.001 per 8-bit channel; fewer than 0.001% of channels differ by more than 8/255. Small raster differences remain.
- Startup, minimal controls, save/reset, pause/step, repeated resize/DPR changes, embedded-canvas use, disposal, missing assets, unsupported WebGPU, and simulated device-loss recovery.
- A 63-second browser soak completed two cycles and 20 flicker redraws at approximately 60 fps. Fixed memory/target counts remained stable; retained JS heap grew by about 110 KB after collection. Freeze/resume did not advance suspended time. No runtime/GPU errors were observed.
- A private GitHub Actions workflow rebuilds WASM and checks deterministic geometry/atlas/animation behavior on Linux. Browser/GPU checks are separate local tools.

See [runtime documentation](../dos-maze/README.md) and [evidence](../dos-maze/evidence/). Physical multi-device acceptance remains pending. Repository visibility and Pages deployment remain unchanged.
