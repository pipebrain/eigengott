EIGENGOTT v0.1.1
Finite Selves · equipment · Recomposition


Run / checkpoints
Automatic checkpoints at encounter boundaries. Mid-wave reconstruction resumes from the last boundary. Death ends this prototype run; narrative death transfer is later work.
Encounter / arena
Opponents defeated → Collapse → Return → shared Release. One gun and worn armor. Defeated Selves leave equipment in the loot interface. Choose one random drop while falling through the void.


Character / test inventory
All 18 models, 33 named roster entries and their skins are selectable. Opponents normally share your selected character. Reset the encounter to refresh existing opponents. Weapon changes require clearance.


Equipment / feedback
One fragment per gun / armor piece. Installation currently uses a development status message. All swaps require physical clearance.
Opponents / testing
Navigation routes are precomputed after arena validation. This test uses original chase / strafe / aiming logic inspired by Quake; it does not embed the Quake botlib.


Collapse / void / return
Outside-in collapse, ten-second falling selection, safe landing, then outward rebuilding. Deleted groups lose render and collision together. A new fully validated structure activates while the arena is fully collapsed.


Structural Recomposition
The landing clump is preserved. New rooms, wall openings and height profiles are generated and validated before Collapse; rendering, collision and navigation activate together in the void.
Regional 3D skies
Three 3D box/pyramid scenes, two scrolling cloud textures. Sky ceilings stay solid to bodies and projectiles.
