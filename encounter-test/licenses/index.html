OpenArena media / credits / sources

The interactive EIGENGOTT test includes OpenArena 0.8.8 artwork and sounds by the OpenArena contributors. Their original copyright and GPL notices are preserved below. This is an independent engine test, not an official OpenArena release.

GNU GPL version 2 · Original contributors · File hashes · Return to the test

Source archives contain the unmodified MD3 models, skins, full-resolution texture/sound inputs and shader scripts used by our offline converter. The authoring archives mirror the relevant available Blender, image and model projects from OpenArena SVN revision 951. Authoring provenance and individual source hashes.

Converted runtime media use vertex-frame interpolation, compact normal data and PNG textures limited to 512 pixels per side. Our renderer implements simple lit/alpha-tested materials; it does not reproduce every legacy shader stage. Original inputs and authoring files accompany these transformations.
